# برنامج متابعة البورصة المصرية ومؤشرات تعويم وأرشيف المؤسسات

برنامج متكامل لحل مشكلة بطء وتعليق موقع البورصة المصرية وتجاوز جدار الحماية (F5 WAF)، مع ربطه بموقع **تعويم (Ta3weem)** لجلب أسعار العملات لحظياً، وتوفير **أرشيف كامل لمعاملات المؤسسات (دخل / خرج / صافي)** لمقارنتها يومياً وأسبوعياً وشهرياً.

---

## 🌟 المزايا المضافة حديثاً:

### 1. ربط أسعار الصرف بموقع تعويم (ta3weem.com)
* جلب أسعار العملات الرئيسية لحظياً من موقع تعويم:
  - 🇺🇸 الدولار الأمريكي (USD)
  - 🇪🇺 اليورو الأوروبي (EUR)
  - 🇸🇦 الريال السعودي (SAR)
  - 🇦🇪 الدرهم الإماراتي (AED)
  - 🇰🇼 الدينار الكويتي (KWD)
  - 🇬🇧 الجنيه الإسترليني (GBP)
  - 🪙 أسعار الذهب (عيار 21، عيار 24، جنيه الذهب)
* قائمة جانبية (Sidebar) أنيقة تعرض أسعار الشراء والبيع ونسبة التغير، ومجهزة معمارياً لإضافة أي مؤشرات أخرى مستقبلاً.

### 2. أرشيف معاملات المؤسسات (دخل / خرج)
* **حسابات دقيقة:**
  - **دخل:** حجم السيولة الداخلة عبر شراء المؤسسات (Inflow).
  - **خرج:** حجم السيولة الخارجة عبر بيع المؤسسات (Outflow).
  - **الصافي:** الفرق بين الداخل والخارج، مصنفاً حسب المؤسسات المصرية والعربية والأجنبية.
* **مقارنات زمنية مرنة:**
  - **مقارنة يومية (Daily):** تتبع جلسات التداول يوم بيوم.
  - **مقارنة أسبوعية (Weekly):** تجميع تلقائي لأداء كل أسبوع تداول.
  - **مقارنة شهرية (Monthly):** رصد حركة السيولة المؤسسية شهرياً.
* **رسم بياني تفاعلي (Interactive Flow Chart):** منحنى يوضح مسار السيولة الداخلة والخارجة وصافي التدفق.
* **تصدير الأرشيف إلى Excel:** زر مخصص لتصدير جداول الأرشيف والمقارنات في ملف إكسيل مستقل.
